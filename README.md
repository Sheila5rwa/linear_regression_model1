# AgriSmart Africa: Crop Yield Predictor

**Mission:** AgriSmart Africa empowers local farmers with predictive agricultural tech to secure food production against unpredictable climate changes.
**Problem:** Farmers face unpredictable harvests; this linear regression tool predicts exact crop yields based on rain, temperature, and inputs to allow for economic planning.
